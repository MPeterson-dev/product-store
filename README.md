# product-store
A full-stack product store built with Vue.js, Pinia, and ASP.NET Core (C#), featuring a REST API, product catalog, search, and category filtering.

## Roadmap

- [ ] Bootstrap responsive layouts and components
- [ ] Less custom styling
- [ ] Shopping cart with Pinia
- [ ] Entity Framework Core and SQL Server
- [ ] Product sizes, colors, and inventory
- [ ] Demo checkout and order history
- [ ] Automated tests and CI/CD
